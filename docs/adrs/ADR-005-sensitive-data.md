# ADR-005: dados sensíveis de participantes

- Status: aceito
- Data: 2026-08-04

O EthPhish não armazenará senhas, OTPs, cartões, documentos ou credenciais reais
digitadas por participantes. Apenas a ocorrência, o tipo de campo e metadados
comportamentais autorizados poderão ser persistidos. A adequação do legado será
tratada antes de qualquer piloto.
